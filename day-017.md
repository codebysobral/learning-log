# Day 017

## Topics Studied
- GitHub repository topics
- Repository descriptions in the "About" section
- Pinned repositories: selection criteria
- Project README vs. Profile README

## What I Learned
Today I learned that a well-organized GitHub profile is more than just code. Adding meaningful descriptions and relevant topics makes repositories easier to discover and understand. I also learned how to choose the most important projects to pin on my profile and the difference between a project README, which explains a specific project, and a profile README, which introduces me as a developer.

## Practice
- Added descriptions and topics to all relevant repositories
- Configured pinned repositories
- Improved the `cardapio-digital` project README

## Challenges
Choosing which repositories to pin was more difficult than I expected because I wanted to highlight projects that best represent my current skills. I also spent some time deciding which topics were the most relevant for each repository.

## Notes
A well-structured GitHub profile creates a much better first impression for recruiters and other developers. Small details, like descriptions and topics, make a significant difference in professionalism.
