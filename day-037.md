# Day 037

## Topics Studied

* Specialized input types: email, password, number, date, tel, and URL
* Checkboxes for multiple selections
* Radio buttons for a single choice within a group
* File input and the `accept` attribute
* `value` and `checked` attributes

## What I Learned

I learned how to use different input types to collect specific kinds of information. I also learned the difference between checkboxes and radio buttons, and how to restrict uploaded files with `accept`.

## Practice

* Added multiple specialized input types to a form
* Created a checkbox group for studied technologies
* Created radio buttons for experience level
* Added a file upload field with a type restriction

## Challenges

The main challenge was remembering which input type to use for each situation and understanding the difference between checkbox and radio groups.

## Notes

Using the correct input type makes forms more organized and user-friendly. The `value` attribute defines the submitted value, while `checked` sets a checkbox or radio button as selected by default.
