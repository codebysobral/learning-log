# Day 030

## Topics Studied

* Hierarchical headings (`h1-h6`) and the single `h1` rule
* Paragraphs, `br`, and `hr`
* Semantic emphasis (`strong`, `em`) vs. visual styling (`b`, `i`)
* Unordered, ordered, definition, and nested lists
* Additional text elements (`mark`, `small`, `sub`, `sup`)

## What I Learned

I learned how to structure text content in HTML using headings, paragraphs, lists, and semantic emphasis. I also understood the difference between semantic and purely visual elements and when each one should be used.

## Practice

* Expanded the homepage with headings, paragraphs, and emphasis
* Created unordered, ordered, definition, and nested lists
* Completed an exercise using the main text elements

## Challenges

The main challenge was remembering the differences between similar HTML elements and choosing the correct one for each situation, especially semantic vs. visual emphasis.

## Notes

* Use headings to create a clear content hierarchy.
* Keep only one main `h1` per page.
* Prefer semantic elements when they communicate meaning.
* Lists can be nested to organize related information.
