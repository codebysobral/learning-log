# Day 031

## Topics Studied

* `<a>` tag and `href` attribute
* Internal, external, anchor, email, and phone links
* Relative vs. absolute paths
* Security with `rel="noopener noreferrer"`
* Introduction to the `<nav>` element

## What I Learned

I learned how to create links using the `<a>` tag and how the `href` attribute defines the destination. I also learned the difference between relative and absolute paths and how to create links to other pages, sections of the same page, email addresses, phone numbers, and external websites.

I also understood that `rel="noopener noreferrer"` helps make external links safer when using `target="_blank"`.

## Practice

* Created `sobre.html` and `contato.html`
* Built functional navigation between the three pages of the mini site
* Added anchor, email, and secure external links

## Challenges

I had some difficulty understanding the difference between relative and absolute paths and knowing which one to use in each situation. I also had to pay attention to the link structure to avoid navigation errors.

## Notes

I realized that organizing folders properly makes working with relative paths much easier. I also learned that the `<nav>` element helps keep the website's navigation clear and organized.
