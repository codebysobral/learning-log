# Day 033

## Topics Studied
- The "div soup" problem
- header, nav, main, section, article, aside, footer
- Conceptual difference between section and article
- When to still use div consciously

## What I Learned
- Semantic HTML improves code readability, accessibility, and maintainability.
- Each semantic element has a specific purpose and helps describe the structure of a page.
- A section groups related content within a page, while an article represents independent, self-contained content.
- Div elements are still useful when no semantic element accurately represents the content.

## Practice
- Semantic restructuring of the 4 pages from the mini website
- Use of article and aside where appropriate
- Complete exercise creating a fully semantic fictional webpage

## Challenges
- Distinguishing when to use section versus article in real scenarios.
- Avoiding the habit of using div elements for every layout structure.
- Choosing the most appropriate semantic element for certain content blocks.

## Notes
- Semantic HTML benefits both users and search engines.
- A well-structured document is easier to understand and maintain.
- Using semantic tags reduces unnecessary div nesting and improves code organization.
